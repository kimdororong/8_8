# 크로스 축구 - 낙서 공 ⚽✏️

낙서판에 마우스로 그림을 그리고 **⚽ 차기!** 를 누르면 **그린 그림이 그대로** 날아가요.
공은 내 모니터의 벽에서 튕기다가, **옆사람 쪽 면으로 나가면 옆사람 화면에서 튀어나와요.**
경기장 창은 클릭이 통과해서 하던 일은 그대로 할 수 있어요.

## 시작하기 (Windows, Python 3.8+ · 추가 설치 없음)
같은 와이파이에 있는 두 PC에서 각자:

1. **`play.bat` 더블클릭** (또는 `python cross_soccer.py`)
2. 시작 화면에서 **① 내 모니터가 왼쪽인지 오른쪽인지** 고르기 — 두 사람은 서로 다른 쪽을 골라야 해요
3. **② 한 명은 `방 만들기`** → 화면에 IP와 4자리 코드가 떠요
4. **다른 한 명은 IP와 코드를 넣고 `참가하기`**

- 방을 만들 때 Windows 방화벽 창이 뜨면 **허용**을 눌러 주세요.
- 두 사람이 같은 쪽을 고르면 참가가 거절되고 어느 쪽을 골라야 하는지 알려 줘요.

## 규칙
- **그린 낙서가 곧 공**이에요. 크기·모양 그대로, 그린 자리에서 출발해요. (아주 큰 낙서는 골대에 들어갈 수 있게 조금 줄여요)
- 각자 모니터의 **위·아래·바깥쪽 벽**에서 튕기고, **옆사람과 맞닿은 면만** 통과해요.
- **골대**는 각자 **바깥쪽 벽 맨 아래**, 세로 200px예요.
- 내 골대에 공이 들어가면 상대 점수 + **내 화면에 커다란 GOAL!!! 팡파레** 🎉
- **마우스 커서**로 공을 튕겨 낼 수 있어요. (낙서판 위에서는 공을 치지 않아요)
- 공은 최대 6개, 45초가 지나면 사라져요.

## 조작
| | |
|---|---|
| 낙서판 제목줄 끌기 | 낙서판 옮기기 |
| 낙서판 `✕` | 낙서판 닫기 (작은 `✎ 낙서판 열기` 버튼이 남아요) |
| 낙서판에서 왼쪽 드래그 | 그리기 |
| 우클릭 / `지우기` | 지우기 |
| `⚽ 차기!` | 날리기 |
| `Ctrl+Shift+P` | 낙서판 닫기 / 열기 |
| `Ctrl+Shift+Q` | 종료 (상대 화면도 같이 꺼져요) |

## 명령줄로 시작하기 (선택)
```
python cross_soccer.py host --me left          # 내가 왼쪽, 방 만들기
python cross_soccer.py join 192.168.0.5 4821   # 참가 (자리는 방장의 반대쪽)
```
