# 크로스 축구 - 낙서 공 ⚽✏️

내 화면 아래에 작은 **낙서판**이 떠요. 마우스로 그림을 그리고 **⚽ 차기!** 를 누르면
그 그림이 공이 되어 날아가요. 공은 내 모니터의 벽에서 튕기다가, **옆사람 쪽 면으로 나가면
옆사람 화면에서 튀어나와요.** 경기장 창은 클릭이 통과해서 하던 일은 그대로 할 수 있어요.

## 규칙
- 공은 처음부터 있지 않아요. **그린 낙서가 곧 공**이에요. 상대 화면에서도 내가 그린 그림이 (내 색깔로) 빙글빙글 돌며 날아와요.
- 각자 모니터의 **위쪽·아래쪽·바깥쪽 벽**에서 공이 튕겨요. **옆사람 모니터와 맞닿은 면만** 통과해요.
- **골대**는 각자 화면 **아래쪽 바깥 모서리**(왼쪽 사람은 왼쪽 아래, 오른쪽 사람은 오른쪽 아래)에 있고, 가로 폭은 화면의 10%로 좁아요. 작업표시줄 바로 위에 있어요.
- 내 골대에 공이 들어가면 **상대 점수**예요.
- **마우스 커서**로 공을 튕겨 낼 수 있어요. 가만히 있어도 튕기고, 빠르게 휘두르면 더 세게 날아가요. (낙서판 위에서는 공을 치지 않아요.)
- 공은 최대 6개까지 동시에 날릴 수 있고, 45초가 지나면 펑 하고 사라져요.

## 실행 (Windows, Python 3.8+ 만 있으면 돼요. 추가 설치 없음)
같은 와이파이에 있는 두 PC에서:

```
# 왼쪽 사람
python cross_soccer.py host

# 오른쪽 사람 (host 화면에 나온 명령 그대로)
python cross_soccer.py join 192.168.0.5 4821
```

- host를 처음 켜면 Windows 방화벽 창이 뜨는데 **허용**을 눌러 주세요.
- 4자리 코드가 맞아야만 연결돼요. 서로 아는 사람끼리만 쓰세요.

## 조작
| | |
|---|---|
| 낙서판에서 마우스 왼쪽 드래그 | 그리기 |
| 낙서판 우클릭 / `지우기` | 지우기 |
| `⚽ 차기!` | 그림을 공으로 만들어 날리기 |
| `Ctrl+Shift+P` | 낙서판 숨기기 / 보이기 |
| `Ctrl+Shift+Q` | 종료 (상대 화면도 같이 꺼져요) |
