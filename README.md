# 크로스 축구 - 낙서 공 ⚽✏️

낙서판에 마우스로 그림을 그리고 **⚽ 차기!** 를 누르면 **그린 그림이 그대로** 날아가요.
공은 내 모니터의 벽에서 튕기다가, **옆사람 쪽 면으로 나가면 옆사람 화면에서 튀어나와요.**
경기장 창은 클릭이 통과해서 하던 일은 그대로 할 수 있어요.

## 시작하기 (Windows, Python 3.8+ · 추가 설치 없음)
같은 와이파이에 있는 두 PC에서 각자:

1. **`play.bat` 더블클릭** (또는 `python cross_soccer.py`)
2. 시작 화면에서 **① 내 모니터가 왼쪽인지 오른쪽인지** 고르기 — 두 사람은 서로 다른 쪽을 골라야 해요
3. **② 한 명은 `방 만들기`** → 화면에 IP와 4자리 코드가 떠요
4. **다른 한 명은 IP와 코드를 넣고 `참가하기`**

- 방을 만들 때 Windows 방화벽 창이 뜨면 **허용**을 눌러 주세요.
- 두 사람이 같은 쪽을 고르면 참가가 거절되고 어느 쪽을 골라야 하는지 알려 줘요.

## 규칙
- **그린 낙서가 곧 공**이에요. 크기·모양 그대로, 그린 자리에서 출발해요. (아주 큰 낙서는 골대에 들어갈 수 있게 조금 줄여요)
- 각자 모니터의 **위·아래·바깥쪽 벽**에서 튕기고, **옆사람과 맞닿은 면만** 통과해요.
- **골대**는 각자 **바깥쪽 벽 맨 아래**, 세로 200px예요.
- 내 골대에 공이 들어가면 상대 점수 + **내 화면에 커다란 GOAL!!! 팡파레** 🎉
- **마우스 커서**로 공을 튕겨 낼 수 있어요. (낙서판 위에서는 공을 치지 않아요)
- 공은 최대 6개, 45초가 지나면 사라져요.

## 조작
| | |
|---|---|
| 낙서판 제목줄 끌기 | 낙서판 옮기기 |
| 낙서판 `✕` | 낙서판 닫기 (작은 `✎ 낙서판 열기` 버튼이 남아요) |
| 낙서판에서 왼쪽 드래그 | 그리기 |
| 우클릭 / `지우기` | 지우기 |
| `⚽ 차기!` | 날리기 |
| `Ctrl+Shift+P` | 낙서판 닫기 / 열기 |
| `Ctrl+Shift+Q` | 종료 (상대 화면도 같이 꺼져요) |

## 명령줄로 시작하기 (선택)
```
python cross_soccer.py host --me left          # 내가 왼쪽, 방 만들기
python cross_soccer.py join 192.168.0.5 4821   # 참가 (자리는 방장의 반대쪽)
```

## 테스트
```
python -m unittest
```

# 페널티 대결 🧤⚽ (`penalty_duel.py`)

한 명은 **키커**, 한 명은 **골키퍼**로 1:1 대결이에요. 같은 와이파이의 PC 두 대에서 해요.
**3인칭 시점**이라 내 캐릭터의 뒷모습이 보여요.

## 시작하기
1. 두 사람 모두 **`play_duel.bat` 더블클릭** (또는 `python penalty_duel.py`)
2. 한 명은 **방 만들기** → IP와 코드가 떠요. 다른 한 명은 그걸 넣고 **참가하기**

## 조작
| 키 | 키커 ⚽ | 골키퍼 🧤 |
|---|---|---|
| 방향키 | 이동 (공에 몸이 닿으면 굴러가요 = 드리블) | 이동 (**화면 기준**: 왼쪽 키 = 화면 왼쪽) |
| 스페이스 | **차기** — 누르고 있는 방향키 쪽으로 날아가요 (↑ 골대 쪽, ↓ 뒤쪽, ←→ 옆, 대각선도 돼요. 아무 키도 안 누르면 바라보는 방향) | **다이빙** — 방향키 쪽으로 순간 이동 (1.3초 충전) |
| `S` | **공수교대** (준비 화면: 이번 판부터 / 결과 화면: 다음 판부터) | 같음 |
| `F5` | 캐릭터 그림 다시 불러오기 | 같음 |
| `F11` | 전체화면 | 같음 |
| `R` | 게임이 끝나면 다시 하기 | 같음 |
| `Esc` | 종료 | 같음 |

## 규칙
- 한 판마다 키커와 골키퍼가 **자동으로 바뀌어요.** 각자 **5번씩** 차고, 골이 많은 쪽이 승리! 비기면 연장전이에요.
- 키커는 **노란 슛 라인** 위로 못 가요. 라인 뒤에서 공을 옆으로 굴려 자리를 잡고 차세요.
- 골키퍼는 골대 앞 구역에서만 움직여요. 키커가 자리를 잡는 걸 보고 미리 따라붙어도 되지만, 키커가 방향을 갑자기 바꿔서 차면 못 막을 수 있어요.
- 공을 골키퍼가 건드리면 막은 걸로 하고 그 판이 끝나요. 슛이 빗나가거나 14초가 지나도 끝나요.

## 창
일반 창이라 **옮기고, 키우고, 줄이고, 최소화, 닫기**가 다 돼요. 크기를 바꾸면 화면이 알맞게 늘어나고 줄어들어요.

## 캐릭터 그림 바꾸기
`assets/` 폴더에 PNG를 넣으면 돼요. **게임을 켠 채로 저장하면 바로 반영**되고(안 되면 `F5`), **상대 화면에도 자동으로 전달**돼요. 각자 자기 PC에 자기 그림만 넣으면 서로 상대 캐릭터가 보여요. 일러스트레이터 내보내기 방법은 `assets/README.md`에 있어요.
