# 크로스 축구 ⚽

두 사람의 화면 위에 투명한 경기장이 떠요. 공이 내 화면 끝을 넘어가면 옆사람 화면에서 튀어나오고,
마우스 커서에 닿으면 튕겨요. 창은 클릭이 통과해서 하던 일은 그대로 할 수 있어요.

## 규칙
- 왼쪽 사람 화면의 **왼쪽 위 모서리**, 오른쪽 사람 화면의 **오른쪽 위 모서리**에 빨간 골대가 있어요 (화면 세로의 1/5).
- 공이 자기 골대에 들어가면 상대 점수! 실점한 쪽이 2초 뒤에 서브해요.
- 커서로 공을 막거나 쳐서 넘겨요. 커서가 가만히 있어도 튕기고, 빠르게 휘두르면 더 세게 날아가요.

## 실행 (Windows, Python 3.8+ 만 있으면 돼요. 추가 설치 없음)
같은 와이파이에 있는 두 PC에서:

```
# 왼쪽 사람
python cross_soccer.py host

# 오른쪽 사람 (host 화면에 나온 명령 그대로)
python cross_soccer.py join 192.168.0.5 4821
```

- host를 처음 켜면 Windows 방화벽 창이 뜨는데 **허용**을 눌러 주세요.
- 4자리 코드가 맞아야만 연결돼요. 서로 아는 사람끼리만 쓰세요.
- **Ctrl+Shift+Q** 를 누르면 언제든 종료돼요 (상대 화면도 같이 꺼져요).
