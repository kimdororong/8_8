# 캐릭터 그림 넣는 곳

이 폴더에 아래 이름의 **PNG** 파일을 넣으면, 게임이 코드로 그린 기본 캐릭터 대신 그 그림을 써요.
없는 파일은 기본 캐릭터로 그대로 나와요. (일부만 바꿔도 돼요)

| 파일 | 언제 보이나요 |
|---|---|
| `kicker_back.png`  | 내가 키커일 때 내 캐릭터 (뒷모습) |
| `kicker_front.png` | 상대가 키커일 때 상대 캐릭터 (앞모습) |
| `keeper_back.png`  | 내가 골키퍼일 때 내 캐릭터 (뒷모습) |
| `keeper_front.png` | 상대가 골키퍼일 때 상대 캐릭터 (앞모습) |
| `player_back.png` / `player_front.png` | **역할 구분 없이 한 캐릭터로 쓸 때** (키커든 골키퍼든 이 그림. 위 4개가 있으면 그게 우선) |

## 그림 규격
- 배경은 **투명**
- **발 밑이 그림의 맨 아래 가운데**에 오게 (땅에 서 있는 자리예요)
- 전신이 보이는 세로로 긴 그림, 높이 약 300~600px 권장 (게임이 알아서 줄이고 늘려요)
- SVG는 PNG로 바꿔서 넣어야 해요 (게임 화면 도구가 SVG를 직접 못 그려요)

## 일러스트레이터(Illustrator)에서 바로 넣기
1. 캐릭터를 그려요. **발 밑이 아트보드의 맨 아래 가운데**에 오게, 캐릭터가 아트보드를 꽉 채우게 그리면 편해요.
2. `파일 > 내보내기 > 다른 이름으로 내보내기...` (또는 `자산 내보내기`)
   - 형식: **PNG**
   - **`아트보드 사용`** 체크 (아트보드 하나만 내보내려면 범위 지정)
   - 파일 이름은 위 표의 이름 그대로 (예: `keeper_back.png`)
   - 저장 위치는 게임 폴더의 `assets` 폴더
3. PNG 옵션 창에서 **배경색: 투명**, 해상도 **150ppi 이상** 권장
4. 게임이 켜져 있으면 **저장하고 1초쯤 뒤에 자동으로 바뀌어요.** 안 바뀌면 게임 창에서 **F5**를 눌러요.

## 상대에게 내 캐릭터 보여주기 (자동)
접속하면 **내 `assets` 폴더의 그림이 상대에게 자동으로 전달돼요.** 상대 화면에서는 내 캐릭터가 **내가 만든 `*_front` 그림(앞모습)**으로 보이고,
내 화면에서는 상대 캐릭터가 **상대가 보낸 `*_front` 그림**으로 보여요. 각자 자기 PC에 자기 그림만 넣으면 돼요.

- 게임 중에 그림을 저장하면 상대 화면도 바로 바뀌어요.
- 상대가 그림을 안 넣었으면 기본 캐릭터가 보여요.
- 그림이 너무 크면(약 300KB 또는 2000px 초과) 보내기 전에 자동으로 줄여요. 미리 세로 500px 안팎으로 내보내면 제일 좋아요.
- 상대가 보낸 그림은 저장되지 않고 게임을 끄면 사라져요.

## 걷는 동작 그림 (선택)
움직일 때 다리가 움직이는 걸 직접 그린 그림으로 보이게 하려면, 위 4개 이름 뒤에 `_walk1`, `_walk2`를 붙인
그림을 더 넣으세요. 걷는 동안 `walk1`과 `walk2`가 번갈아 나와요. (예: `kicker_back_walk1.png`, `kicker_back_walk2.png`)

- 없으면: 기본 캐릭터는 다리가 번갈아 올라가고, 넣은 그림은 걸을 때 통통 튀어요.
- `walk1`, `walk2`는 서 있는 그림과 **같은 크기·같은 발 위치**로 내보내야 해요.
- 파일: `kicker_back_walk1/2`, `kicker_front_walk1/2`, `keeper_back_walk1/2`, `keeper_front_walk1/2`
