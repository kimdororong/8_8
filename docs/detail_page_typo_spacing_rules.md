# 상세페이지 타이포 · 여백 기준서 (초안 v0.1)

용도: AI(Codex)가 JSON으로 상세페이지를 만들 때 따르는 디자인 규칙, 그리고 결과물 자동 점검 기준.
상태: **초안.** 아래 수치는 일반적인 가정에 기반하며, 실제 폰트와 결과물로 테스트해서 디자이너가 확정한다.

## 0. 가정 (먼저 확인할 것)
| 항목 | 가정 | 확인 방법 |
|---|---|---|
| 캔버스 너비 | **860px** (카페24·스마트스토어 상세 영역에 흔히 쓰는 폭) | 판매처(카페24/스마트스토어)의 현재 권장 폭 확인 |
| 열람 환경 | 대부분 모바일. 860px 이미지를 폭 약 390px 화면에 줄여 보면 **약 0.45배** | 판매처 통계 |
| 폰트 | 한글 가독성 좋은 상업 무료 폰트 1종 (예: Pretendard, Noto Sans KR 등 OFL 계열) | 폰트 라이선스 문서 확인 |
| 단위 | 모든 수치는 860px 캔버스 기준 px | 팀원 JSON의 단위 확인 |

> 핵심 원리: 모바일에서 0.45배로 보이므로 **캔버스 기준 28px 글자는 화면에서 약 12.6px**이다. 그래서 상세페이지 글자는 일반 웹보다 훨씬 커야 한다.

## 1. 타이포그래피

### 1-1. 서체 규칙
1. **서체는 1종**만 쓴다 (한글+영문 모두). 장식용 서체는 영문 로고/숫자 강조에 한해 최대 1종 추가.
2. **굵기는 3단계만**: Regular(400) / SemiBold(600) / Bold(700). 그 외 굵기 금지.
3. 한 섹션 안에서 **글자 크기 단계는 최대 4개**.
4. 한 페이지 전체에서 **크기 단계는 아래 스케일 값만** 사용 (임의 값 금지).

### 1-2. 크기 스케일 (860px 캔버스 기준)
| 역할 | 크기 | 굵기 | 줄간격 | 자간 | 비고 |
|---|---|---|---|---|---|
| 히어로 타이틀 | 64~72px | Bold | 1.25 | -3% | 최대 2줄 |
| 섹션 타이틀 (H2) | 48~56px | Bold | 1.3 | -2.5% | 최대 2줄 |
| 소제목 (H3) | 36~40px | SemiBold | 1.35 | -2% | 최대 2줄 |
| 리드 문장 | 32~34px | Medium~SemiBold | 1.5 | -1.5% | 최대 3줄 |
| 본문 | 28~30px | Regular | 1.65 | -1% | 기본값 |
| 캡션·주석·표 | 24px | Regular | 1.5 | -0.5% | **법정 고지·주석·표에만 사용** |

**절대 하한: 24px.** 이보다 작은 글자 금지. 본문은 28px 이상.
인접 단계 간 크기 비율은 **1.25배 이상**으로 차이를 둔다 (위계가 흐려지지 않게).

### 1-3. 줄바꿈 · 텍스트 블록
1. **어절 단위 줄바꿈**(keep-all): 단어 중간에서 끊지 않는다.
2. **한 줄 글자 수**: 본문 기준 16~26자. 이보다 길면 줄 폭을 줄이거나 문장을 나눈다.
3. **홀로 남는 줄(고아 줄) 금지**: 마지막 줄에 1~2글자만 남지 않게 줄 폭이나 문구를 조정.
4. **정렬**: 한 섹션 안에서 정렬은 하나만 (가운데 또는 왼쪽). **가운데 정렬은 3줄 이하**일 때만. 4줄 이상이면 왼쪽 정렬.
5. **텍스트 블록 분량**: 한 블록 최대 3문장 / 80자. 한 섹션 총 텍스트는 **200자 이하**를 권장 (정보 표 제외).
6. 문단 안에서 **강조는 섹션당 1종류**: 색, 굵기, 밑줄 중 하나만. 두 가지 이상 섞지 않는다. 강조 구간은 한 문장에 최대 1곳.

### 1-4. 색과 대비
1. 본문·소제목 글자색과 배경의 **대비 4.5:1 이상**.
2. 큰 글자(타이틀) 대비 **3:1 이상**.
3. **사진/이미지 위 글자**: 반투명 오버레이(어두운 레이어 40% 이상)나 단색 박스를 깔아서 대비를 확보한다. 오버레이 없이 사진 위에 글자 금지.
4. 글자색은 페이지당 **주색 1 + 보조 1 + 무채색(검정/회색/흰색)** 으로 제한.

## 2. 여백

### 2-1. 기본 단위
- **8px 그리드**: 모든 간격은 8의 배수.
- **허용 간격 값**: 8 / 16 / 24 / 32 / 48 / 64 / 80 / 120 / 160 (이 외 값 금지).

### 2-2. 좌우 여백
- **좌우 안쪽 여백 60px** (콘텐츠 폭 740px).
- 글자는 가장자리에서 **최소 40px** 이상 떨어진다.
- 이미지는 전체 폭(full-bleed, 860px) 또는 콘텐츠 폭(740px) 중 하나만 쓴다 (중간 값 금지).

### 2-3. 섹션 간격 (세로)
| 위치 | 값 |
|---|---|
| 일반 섹션 위·아래 안쪽 여백 | **120px** |
| 히어로 섹션 위·아래 | 160px |
| 섹션 사이 배경이 같을 때 | 구분선 대신 위 여백만으로 구분 |
| 한 페이지 내 **섹션 안쪽 여백은 최대 2종류**만 | (예: 120과 160) |

### 2-4. 섹션 내부 간격 (근접성 원칙)
**같은 그룹 안의 간격은 그룹 사이 간격의 절반 이하**여야 한다.

| 요소 | 간격 |
|---|---|
| 타이틀 → 소제목 | 24px |
| 타이틀(또는 소제목) → 본문 | 32px |
| 문단 ↔ 문단 | 24px |
| 이미지 ↔ 설명 글 | 48~64px |
| 카드 ↔ 카드 | 24~32px |
| 카드 안쪽 여백 | 40px |
| 그룹 ↔ 그룹 (예: 특징 1 ↔ 특징 2) | 64px |
| 아이콘 ↔ 글자 | 16px |
| 표 셀 안쪽 여백 | 상하 16px / 좌우 24px |

### 2-5. 리듬
1. 글이 많은 섹션이 **연속 2개를 넘지 않게** 하고, 사이에 이미지 중심 섹션을 둔다.
2. 섹션마다 **전달 메시지는 1개**.
3. 배경색은 **인접 섹션과 달라야** 구분이 되지만, 한 페이지에서 **배경색은 3종 이하**.
4. 같은 유형의 요소(카드, 아이콘)는 **크기·간격·정렬을 동일**하게 유지.

## 4. AI에게 줄 지침 (Codex 프롬프트에 그대로 넣는 용도)

```
[타이포·여백 규칙 — 반드시 지킬 것]
- 캔버스 860px, 좌우 여백 60px, 콘텐츠 폭 740px.
- 글자 크기는 이 값만 사용: 72/64(히어로), 56/48(H2), 40/36(H3), 34/32(리드), 30/28(본문), 24(캡션·표).
- 24px 미만 글자 금지. 본문은 28px 이상.
- 서체는 1종, 굵기는 400/600/700만.
- 줄간격: 타이틀 1.25~1.35, 본문 1.65.
- 한 줄에 본문 16~26자. 어절 단위로 줄바꿈. 마지막 줄에 1~2글자만 남기지 말 것.
- 가운데 정렬은 3줄 이하일 때만. 한 섹션 안에서 정렬 혼용 금지.
- 간격은 8의 배수이며 이 값만 사용: 8/16/24/32/48/64/80/120/160.
- 섹션 위아래 여백 120px(히어로는 160px). 섹션 안쪽 여백 종류는 최대 2개.
- 같은 그룹 안의 간격은 그룹 사이 간격의 절반 이하로.
- 한 섹션에는 메시지 1개, 텍스트는 200자 이하.
- 사진 위 글자는 반드시 오버레이로 대비를 확보.
- 글자색은 주색 1 + 보조 1 + 무채색. 본문 대비 4.5:1 이상.
- 규칙을 지킬 수 없으면 임의로 어기지 말고 문구를 줄이거나 섹션을 나눠서 해결할 것.
```

## 5. 사람 검수용 채점표 (타이포 · 여백)
결과물 1건당 각 항목 1~5점. 개선 전/후 비교에 사용.

| 항목 | 질문 | 1점 | 5점 |
|---|---|---|---|
| 가독성 | 모바일 크기(폭 390px)로 줄여도 편하게 읽히는가 | 작아서 못 읽음 | 전부 편하게 읽힘 |
| 위계 | 제목·소제목·본문의 차이가 한눈에 보이는가 | 구분 안 됨 | 시선 흐름이 분명 |
| 줄바꿈 | 어색한 줄바꿈·고아 줄이 없는가 | 많음 | 없음 |
| 근접성 | 관련 있는 것끼리 가까이 묶여 있는가 | 간격이 제각각 | 묶음이 분명 |
| 일관성 | 같은 역할의 요소가 같게 처리되는가 | 제각각 | 완전 일관 |
| 리듬 | 빽빽함과 여유가 번갈아 오는가 | 답답/휑함 | 호흡이 좋음 |
| 여백 | 좌우·상하 여백이 충분하고 균일한가 | 갑갑하거나 들쭉날쭉 | 안정적 |

총점 35점 만점. **28점 이상이면 합격 후보**, 21점 미만이면 규칙 또는 프롬프트를 수정한다.

## 6. 적용 순서
1. 이 문서를 디자이너가 검토하고 수치를 확정한다 (특히 폰트 크기, 섹션 여백).
2. 4번 지침을 팀원 프로그램의 프롬프트에 넣어서 **적용 전/후** 결과를 같은 상품으로 비교한다.
3. 5번 채점표로 점수를 낸다.
4. 3번 점검 규칙 중 **T1, T2, T10, T12, S3** (필수 수정 항목)부터 코드 검사로 구현한다 (팀원과 협의).
5. 결과를 보고 수치를 조정해 v0.2로 올린다.

## 7. 한계
- 실제 결과물을 보지 못한 상태의 초안이다. 어떤 규칙이 효과가 있고 어떤 게 과한지는 테스트 후 확정한다.
- JSON 스키마(필드 이름, 단위, 폰트 지정 방식)에 맞게 규칙을 변환해야 한다.
- 폰트마다 글자 폭이 달라서 "한 줄 글자 수" 기준은 선택한 폰트로 다시 측정해야 한다.
- 카테고리(식품, 뷰티, 패션 등)에 따라 분위기와 여백의 정도를 조정해야 한다.

# 부록 A. v0.2 변경 제안 (레꼴뜨 상세페이지 1건 근거)

근거: [references/analysis/디자인기준서_근거자료.md](../references/analysis/디자인기준서_근거자료.md)
**주의: 레퍼런스가 1건(가전 상품, 네이버 브랜드스토어)뿐이다.** 규칙으로 확정하려면 5~8건에서 겹치는 범위를 확인해야 한다. 아래는 "v0.1 수치가 이 페이지와 얼마나 다른가"를 보여 주는 제안이다.

## A-1. 확인된 가정
| v0.1 가정 | 근거자료 결과 | 판정 |
|---|---|---|
| 캔버스 폭 860px | 본문 이미지 12장이 모두 **원본 폭 860px** (표시는 848px, 측정) | ✅ 맞음 |
| 글 위주 정보가 이미지에 들어감 | HTML 텍스트 0개 (측정) | ✅ 맞음 |
| 모바일에서 약 0.45배로 축소 | 0.42~0.45배 (추정) | ✅ 비슷함 |

## A-2. 타이포: v0.1이 레퍼런스보다 작다
폰트 크기는 잉크 높이 ÷ 0.82~0.92로 추정한 값이라 **범위로만** 쓴다. (잉크 높이·줄 피치 자체는 측정)

| 역할 | v0.1 | 레퍼런스 | v0.2 제안 | 근거 수준 |
|---|---|---|---|---|
| 섹션 제목 | 48~56 | 63~71 (잉크 58, 3곳 동일) | **64~70** | 상 |
| 히어로 제품명 | 64~72 | 59~66 | 60~72 유지 | 중 |
| 히어로 부제 | 32~34(리드) | 39~44 | 36~44 | 중 |
| 본문(주요) | 28~30 | **34~38** (잉크 31, 피치 50) | **34~38** | 상 |
| 본문(작은 설명) | — | 27~32 | 28~32 | 중 |
| 캡션·라벨 | 24 | 25~33 | 26~32 | 중 |
| 표·정책 | 24 | 23~28 | 24~28 (모바일 10~12px 한계 있음 → 26 권장) | 중 |
| 제목 대비 본문 비율 (잉크) | 약 0.5 (56→28) | **0.53** (측정) | 0.5~0.55 | 상 |
| 본문 줄간격 | 1.65 | 1.3~1.5 (추정, 피치 50 ÷ 폰트 34~38) | **1.4 (1.3~1.5)** | 중 |
| 제목 줄간격 | 1.25~1.35 | 1.2~1.3 | 1.25 | 중 |

→ 핵심: **본문을 28~30에서 34~38로 올려야** 모바일(×0.45)에서 15~17px이 된다. v0.1 값(28~30)은 모바일에서 12.6~13.5px이라 작다.

## A-3. 여백: v0.1이 레퍼런스보다 훨씬 좁다

## A-5. 구성과 리듬
- **글 블록(650~700px)과 사진·GIF(860~1,100px)를 번갈아** 배치 (8회 반복, 추정 상)
- **다크 섹션**을 페이지의 약 1/4, 3/4, 끝 근처에 한 번씩 배치해 긴 흐름을 끊음
- **같은 레이아웃 템플릿을 픽셀 단위로 복제**해서 일관성을 확보 (측정) → 섹션 템플릿 라이브러리의 근거
- 특징 블록의 글 분량: 번호 원 + 제목 1줄 + 본문 2~3줄, **약 60~100자** (v0.1의 "섹션당 200자 이하"는 스펙·정책 섹션에는 맞지만 특징 섹션에는 느슨함)
- 한 줄 분량: 625px 폭에서 한글 약 16~19자(공백 포함 20~25자) → v0.1의 16~26자와 대체로 일치

## A-6. 레퍼런스의 약점에서 나온 규칙 후보
| 약점 (근거자료 7단계) | 규칙 후보 |
|---|---|
| 같은 장점을 3번 반복해 길이가 41,919px(측정) | 같은 장점은 **요약 1번 + 상세 1번까지** |
| HTML 텍스트 0개: 검색·스크린리더·번역 불가 | 판매용 템플릿에는 텍스트 원문(대체 텍스트) 제공 검토 |

## A-7. 아직 모르는 것
- 레퍼런스가 1건이고 **가전 카테고리**라서 식품·뷰티에도 같은 수치가 맞는지 모른다.
- 폰트 크기는 잉크 높이로 추정한 범위이며 실제 폰트는 확인 불가.
- 이 페이지가 "좋은 레퍼런스"인지는 판단이 필요하다. 길이(4만 px)와 정보 반복은 약점이므로 **그대로 따라 하지 않는다.**
