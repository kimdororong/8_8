# FiiX "AI로 그리기"에 먹일 상세페이지 지침 v0.2-draft

## 1. 확인한 구조 (FiiX 플러그인 v0.1.14 배포본의 `ui.html`·`code.js`를 읽은 결과)

- 팀원 계정(`wq184502-dev`)의 레포 `Utopia-download`는 README 제목이 `FiiX-download`인 **배포 전용 레포**(설치 파일만 있고 소스 없음)다. FiiX는 데스크톱 앱 + Figma 플러그인이다.
- 플러그인에는 3개 탭이 있다: **가져오기**(웹 캡처 → Figma), **AI로 그리기**, **AI에 보내기**(Figma → JSON).
- **"AI로 그리기"는 자동 호출이 아니라 복사·붙여넣기 방식이다.**
  1. 플러그인의 [프롬프트 복사] → 2. AI 대화창(ChatGPT·Claude 등)에 붙여넣고 맨 아래 `[만들 화면]`에 원하는 화면을 적음 → 3. AI가 준 JSON을 플러그인에 끌어다 놓으면 Figma 레이어로 그려짐.
- 이 플러그인이 AI에게 주는 프롬프트(`DESIGN_PROMPT`)에는 **JSON 형식 규칙만** 있고 디자인 품질 규칙(글자 크기, 간격, 색)은 없다. 예시 화면도 "1999년 감성 로그인 화면"이다. → 퀄리티가 낮은 직접적인 원인 후보.
- JSON은 **모든 요소를 x, y, width, height 절대 좌표(px)** 로 쓰는 형식이다. 간격 규칙은 AI가 y 좌표를 누적 계산해서 지켜야 한다.
- 형식 규칙의 예시 글자 스타일은 `fontFamily "Pretendard", fontSize 16, lineHeight 24(px)` 이다. lineHeight는 **px 값**으로 쓰게 되어 있다.

## 2. 사용 방법 (코드 수정 없음)

1. 플러그인 [AI로 그리기] → **[프롬프트 복사]**
2. AI 대화창에 붙여넣는다.
3. 그 아래(`[만들 화면]` 위)에 **아래 3번의 지침 블록**을 붙인다.
4. `[만들 화면]`에 상품 정보를 적는다 (아래 4번 양식).
5. AI가 준 JSON을 플러그인에 넣어 그린다.

## 3. 붙여 넣을 지침 블록 (FiiX 형식용)

```
[상세페이지 디자인 규칙]
JSON 형식은 [형식 규칙]을 따르고, 디자인 판단은 아래 규칙을 우선한다.

■ 캔버스
- 프레임 폭 860, 높이는 내용에 맞게 정한다(세로로 긴 한 장).
- 글 블록은 폭 624, x=118(가운데), textAlign "center". 본문이 4줄 이상이면 textAlign "left".
- 이미지·카드는 x=64, 폭 732. 풀폭 이미지는 x=0, 폭 860.

■ 글자 (fontFamily는 "Pretendard" 로 통일)
- fontSize는 이 값만 쓴다: 제목 72/64, 부제 44/40/36, 본문 38/34, 보조 본문 32/28, 캡션·표 30/26.
  24 미만 금지. 본문은 32 이상.
- lineHeight는 px 숫자로 쓴다. 제목은 fontSize×1.25 (64→80, 72→90), 본문은 ×1.4 (28→39, 32→45, 34→48, 38→53).
- fontWeight는 400/600/700만. 제목은 700, 본문은 400.
- 글자색은 #323232 한 가지(어두운 배경은 #FFFFFF). 순검정 금지. 색으로 강조하지 않는다.
- 글 상자 height = 줄 수 × lineHeight. 본문 한 줄은 한글 16~19자(폭 624 기준)이므로,
  글자 수로 줄 수를 계산해서 height를 정한다. 본문은 2~3줄.

■ 간격 (y를 위에서 아래로 누적 계산)
- 간격은 이 값만 쓴다: 8/16/24/32/48/64/72/80/120/160/200/240.
- 특징 블록: 섹션 위 240 → 번호 원(ellipse 지름 86 + 숫자 text) → 64 → 제목 → 72 → 본문. 섹션 아래는 120~160.
- 다음 요소의 y = 이전 요소의 y + 이전 요소의 height + 간격. 모든 요소를 이렇게 계산한다.
- 같은 그룹 안 간격은 그룹 사이 간격의 1/3 이하로 한다.

■ 색·배경
- 배경은 뉴트럴 #EEEEEE / 웜 #F0DFCD / 쿨 #EBF5F7 중 3종 이하 + 다크 #323232. 섹션마다 번갈아 쓴다.
- 이미지 자리 위에 글자를 얹을 때는 반투명 검정(alpha 0.4 이상) rectangle을 먼저 깐다.

■ 구성
- 특징 섹션 = [번호 원 + 1줄 제목 + 2~3줄 본문(60~100자)] → [이미지 자리] 반복.
- 같은 장점은 요약 1번 + 상세 1번까지만 쓴다.
- 상품 정보에 없는 인증·검사·수치는 지어내지 않는다.

■ 출력 전 점검
24 미만 글자, 허용 밖의 크기·간격, 글 폭 624 초과, 요소 겹침, 허용 밖 글자색이 없는지 확인하고 고쳐서 출력한다.
```

## 4. `[만들 화면]` 양식

```
[만들 화면]
상세페이지 1장 (폭 860).
상품: (이름, 종류)
특징 3~5개: (각각 한 줄 요약 + 근거가 되는 사실)
사용법: (있으면)
스펙: (있는 것만)
섹션 순서: 히어로 → 요약 → 특징 → 사용법 → 스펙 → 교환·반품
```

## 5. 주의
- 수치는 **레퍼런스 1건(가전)** 에서 나온 임시 값이다. 전/후 채점으로 검증한다.
- **Pretendard**가 Figma(PC)에 설치돼 있지 않으면 플러그인이 다른 폰트로 바꿀 수 있다. 설치 여부를 확인한다.
- AI가 절대 좌표를 직접 계산하기 때문에 **y 계산 실수(겹침, 간격 오류)** 가 가장 흔한 위반이 될 것이다. 이 위반이 반복되면 "섹션 목록과 내용만 AI가 쓰고 좌표는 코드가 배치"하는 방식을 팀원과 논의한다.
- 플러그인의 **가져오기** 기능은 다른 사이트를 캡처해 Figma로 옮기는 기능이다. 타사 상세페이지를 캡처한 결과를 판매용 산출물에 그대로 쓰면 저작권 문제가 된다. 분석용으로만 쓴다.
