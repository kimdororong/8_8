### 한계 (먼저 읽을 것)
1. 레퍼런스 1건, 가전 카테고리. 식품·뷰티에서 같은 수치가 맞는지 모른다.

3. 이 레퍼런스는 길이(41,919px)와 정보 반복이 약점이다. 수치만 참고하고 구조는 그대로 따르지 않는다.
4. 이 문서의 모든 수치는 **같은 상품으로 적용 전/후 채점**(9장)을 거쳐 조정한다.

## 2. 레퍼런스 분석 요약 (1건)

대상: 레꼴뜨 미니 샌드위치 메이커 (가전), 이미지 15장, 총 41,919px.

| 항목 | 관찰 | 근거 |
|---|---|---|
| 섹션 순서 | 신뢰 배너 3 → 히어로 → 연출 사진 → 핵심 6 아이콘 → 공감 메시지 → 색상 → 공감 질문 → (다크)활용법 도입 → 후기 → 요약 카드 → 특징 01~09 → 사용법 → (다크)세척 → 구성 → 사이즈 → 스펙 → 로고 → 교환·반품 | [측정] |
| 특징 블록 | 번호 원 + 1줄 제목 + 본문 2~3줄 → 사진/GIF 반복 (8회) | [측정] 간격·크기가 3곳 픽셀 단위로 동일 |
| 다크 섹션 | 페이지 약 1/4, 3/4, 끝 근처에 1회씩 | [추정] |
| 글자색 | #323232 한 가지, 강조는 굵기만 | [측정] |
| 본문 대비 | 10~13:1 | [측정] |
| 잘 된 점 | 템플릿 일관성, 번호로 진행 위치 안내, 높은 대비, 다크 섹션의 리듬 | |
| 약점 | 같은 장점 3회 반복, HTML 텍스트 0개, 정책·표 글자 모바일 10~12px, 철자·띄어쓰기 오류, 배너 폭(848)이 본문(860)과 다름 | |

### 공통 패턴이 아니라 "관찰"인 이유
1건이라 패턴이라고 부를 수 없다. 5~8건을 같은 방법으로 분석한 뒤 **겹치는 범위**를 이 장의 "공통 패턴"으로 승격한다.

## 10. AI 지침 (요약본, 팀원 프롬프트용)

```
[상세페이지 디자인 규칙 v0.2-draft]
아래 규칙은 반드시 지킨다. 규칙과 충돌하면 규칙이 우선한다.

■ 1. 절대 규칙
- 캔버스 폭 860px. 모든 이미지·섹션 폭은 860으로 통일한다.
- 글 블록 최대 폭 624px, 가운데 정렬. 이미지·카드의 좌우 여백은 64px.
- 글자 크기는 이 값만 사용한다:
  제목 72/64, 부제 44/40/36, 본문 38/34, 보조 본문 32/28, 캡션·표 30/26(표·정책은 26 이상 권장).
- 24px 미만 글자 금지. 본문은 32px 이상(권장 34~38).
- 서체는 1종, 굵기는 400/600/700만 사용한다.
- 간격은 이 값만 사용한다: 8/16/24/32/48/64/72/80/120/160/200/240.
- 특징 블록 간격: 섹션 위 240, 번호·라벨→제목 64, 제목→본문 72.
- 같은 그룹 안의 간격은 그룹 사이 간격의 1/3 이하로 한다.
- 글자색은 #323232 한 가지(어두운 배경에서는 #FFFFFF). 순검정 금지. 강조는 굵기로만 한다.
- 본문 대비 4.5:1 이상(권장 7:1). 사진 위 글자는 오버레이나 단색 박스를 깐다.

■ 2. 권장 규칙
- 줄간격: 제목 1.25, 본문 1.4.
- 본문 한 블록은 2~3줄. 한 줄은 한글 16~19자. 어절 단위로 줄바꿈하고, 마지막 줄에 1~2글자만 남기지 않는다.
- 가운데 정렬은 3줄 이하일 때만. 사용법·표·정책은 왼쪽 정렬.
- 특징 섹션은 [번호 + 1줄 제목 + 2~3줄 본문] 구조로, 60~100자, 메시지 1개.
- 글 블록과 사진 섹션을 번갈아 배치한다. 같은 장점은 요약 1번, 상세 1번까지만 쓴다.
- 배경은 3계열(뉴트럴·웜·쿨) 이하. 긴 페이지에는 다크 섹션을 1/4, 3/4 지점에 넣는다.

■ 3. 금지
- 임의의 글자 크기·간격, 두 가지 이상의 서체, 순검정 본문
- 한 섹션에 강조 2종 이상, 글자색 2종 초과
- 같은 장점 3번 이상 반복, 이미지 폭 불일치
- 오탈자·띄어쓰기·약어 철자 오류
- 근거 없는 인증·검사·수치 문구를 지어내서 쓰기
- 장식 도형·이모지 남발, 글이 박스를 넘치게 두기

■ 4. 규칙을 지킬 수 없을 때
- 규칙을 어기지 말고 문구를 줄이거나 섹션을 나눠서 해결한다.
- 그래도 안 되면 어떤 규칙 때문에 막혔는지 한 줄로 알린다.
```
