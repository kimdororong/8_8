# ChatGPT 실험용 상세페이지 프롬프트 v0.2-draft

근거: [디자인 기준서 v0.2 초안](design_standard_v0.2_draft.md) (레퍼런스 1건 기반 임시 값)
용도: ChatGPT 대화창에서 제품 사진을 올리고 상세페이지 이미지를 섹션별로 생성하는 실험

## 사용 순서
1. 새 대화를 열고 **① 기준서 프롬프트**를 붙여넣는다 (대화당 한 번). ChatGPT 프로젝트 지침에 넣어 두면 매번 붙이지 않아도 된다.
2. 제품 사진을 올리고 **② 섹션 요청**을 섹션마다 하나씩 보낸다. (한 장에 페이지 전체를 그리게 하지 않는다)
3. 마음에 안 드는 부분은 **③ 수정 요청**으로 고친다.
4. 시간을 기록한다: 처음 뽑는 시간 / 고치는 시간 / 고친 이유.

---

## ① 기준서 프롬프트 (대화 시작 시 한 번)

```
너는 한국 이커머스 상세페이지 디자이너야. 앞으로 내가 요청하는 섹션 이미지를 아래 [디자인 기준]에 맞춰 만들어 줘.
이 기준은 모든 요청에 계속 적용해.

[디자인 기준]

■ 캔버스
- 가로 860px 기준의 세로형 이미지. 섹션 하나씩 만든다.
- 모든 섹션은 같은 가로 폭, 같은 여백 규칙, 같은 글자 스타일을 써서 이어 붙였을 때 한 페이지처럼 보여야 한다.

■ 글자
- 한글은 반드시 내가 따옴표로 준 문구를 한 글자도 바꾸지 말고 그대로 쓴다. 오타, 띄어쓰기 변경, 없는 글자 추가 금지.
- 서체는 깔끔한 고딕(산세리프) 한 종류만 쓴다. 손글씨·장식 서체 금지.
- 크기 위계: 제목은 본문의 약 2배. (가로 860px 기준 제목 약 64~72px, 본문 약 34~38px)
- 본문은 휴대폰으로 봐도 읽힐 만큼 크게. 가로 폭의 약 4% 이상.
- 제목은 굵게, 본문은 보통 굵기. 강조는 핵심 단어만 굵게 하고, 색으로 강조하지 않는다.
- 글자색은 짙은 회색(#323232) 한 가지. 어두운 배경에서는 흰색(#FFFFFF). 순검정 금지.
- 본문은 한 덩어리에 2~3줄. 길면 문구를 줄이지 말고 나에게 먼저 물어본다.

■ 여백·배치
- 글 덩어리의 가로 폭은 전체의 약 73% 이내, 가운데 정렬.
- 여백을 넉넉하게. 섹션 위쪽 여백은 가로 폭의 약 4분의 1 (860px 기준 약 240px).
- 제목과 본문 사이는 본문 글자 높이의 약 2배. 본문 줄 사이는 좁게, 제목-본문 사이는 그보다 넓게, 섹션 사이는 가장 넓게.
- 요소끼리 겹치거나 가장자리에 붙지 않게 한다.

■ 색·배경
- 배경은 한 섹션에 한 가지 단색 또는 사진. 섹션마다 연한 회색(#EEEEEE) / 연한 베이지(#F0DFCD) / 연한 하늘(#EBF5F7) / 짙은 회색(#323232) 중에서 번갈아 쓴다.
  (브랜드 색을 따로 주면 그걸 우선한다)
- 사진 위에 글자를 얹을 때는 사진을 어둡게 처리하거나 단색 상자를 깔아 글자가 잘 읽히게 한다.
- 그라데이션, 네온, 반짝이 효과, 장식 도형, 이모지는 쓰지 않는다.

■ 제품 사진
- 내가 올린 제품 사진의 제품은 모양·색·라벨·로고·글자를 절대 바꾸지 않는다. 다시 그리지 말고 그대로 쓴다.
- 바꿔도 되는 것은 배경, 조명, 소품, 연출뿐이다.
- 제품 사진이 부족하면 제품을 새로 만들어 내지 말고 나에게 사진을 요청한다.

■ 내용
- 내가 주지 않은 사실(인증, 검사 결과, 수치, 효능, 수상)은 절대 지어내지 않는다.
- 섹션 하나에는 메시지 하나만 담는다.

■ 출력 전 확인
이미지를 만들기 전에 아래를 스스로 확인한다.
1. 내가 준 문구가 한 글자도 틀리지 않았는가
2. 제목이 본문의 약 2배인가, 본문이 충분히 큰가
3. 여백이 넉넉하고 요소가 겹치지 않는가
4. 글자색이 한 가지인가
5. 제품 모양·라벨이 원본과 같은가

이해했으면 "준비됨"이라고만 답해.
```

## ② 섹션 요청 (섹션마다 하나씩)

```
[섹션 요청]
섹션 종류: (히어로 / 핵심 특징 / 특징 상세 / 사용법 / 구성품 / 스펙 / 교환·반품 중 하나)
배경: (연한 회색 / 연한 베이지 / 연한 하늘 / 짙은 회색 / 사진)
들어갈 문구 (그대로 쓸 것):
- 제목: "..."
- 본문: "..."
- (번호가 있으면) 번호: "01"
제품 사진: 첨부한 사진 n번 사용. 배치: (가운데 크게 / 오른쪽 / 아래)
분위기: (예: 밝고 깨끗한 주방, 자연광)
크기: 가로 860px 기준 세로형
```

### 섹션별 예시 구성
| 섹션 | 구성 |
|---|---|
| 히어로 | 제품명(제목) + 한 줄 부제 + 제품 사진 크게 |
| 핵심 특징 | 제목 + 특징 3개(각각 짧은 제목 + 한 줄 설명) |
| 특징 상세 | 번호(01) + 제목 1줄 + 본문 2~3줄 + 제품 사진 |
| 사용법 | 제목 + 단계 3~5개 (번호 + 한 줄) |
| 스펙 | 제목 + 표(항목/내용), 왼쪽 정렬 |

## ③ 수정 요청

```
방금 이미지에서 아래만 고쳐 줘. 나머지는 그대로 유지해.
- 고칠 것: (예: 본문 글자를 더 크게 / 제목-본문 사이 여백 넓게 / "○○" 글자가 틀림 → "△△")
- 바꾸지 말 것: 제품 사진, 문구, 배경색
```

## 알아둘 점
- 이미지 생성 AI는 **px 수치를 정확히 지키지 못한다.** 그래서 이 프롬프트는 숫자와 함께 비율(약 2배, 약 73%)로 설명했다.
- **한글 글자가 틀리는지**가 이 실험의 가장 중요한 관찰 포인트다. 자주 틀리면 "글자는 Figma에서 직접 얹고, ChatGPT는 배경·연출 사진만" 방식으로 바꾼다.
- 한 장에 긴 페이지 전체를 그리면 비율 제한과 품질 저하가 생기기 쉬우므로 섹션별로 만든다.
- 배경색(#EEEEEE 등)은 레퍼런스 1건의 값이다. 브랜드 색이 있으면 바꾼다.
- AI로 만든 연출 이미지를 실제 판매에 쓸 때는 플랫폼의 AI 생성 이미지 표시 규정을 확인한다.
