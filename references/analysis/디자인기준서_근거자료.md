## 3단계: 타이포 (이미지 속 글자)

**측정값:** 잉크 높이, 줄 피치, 줄 사이 빈 간격, 글자색.
- 잉크 높이는 글자 위끝~아래끝 픽셀 높이라서 폰트 크기와 다름.
- 줄 피치는 실제 line-height에 해당함.

**추정값:** 폰트 크기 = 잉크 높이 ÷ 0.82~0.92.
- 본고딕·나눔고딕 계열에서 받침 있는 한글의 잉크 높이가 폰트 크기의 약 82~92%라는 일반적 비율을 썼음.

## 6단계: 리듬과 구성

**섹션 순서:** 신뢰 배너×3 → 히어로 → 사진 → 요약 아이콘 → 공감 메시지 → 색상 → 공감 질문 → (다크) 활용법 도입 → 후기 → 요약 카드 → 사진 → **특징 01~09** → 사용법 → (다크) 세척 → 구성 → 사이즈 → 스펙 → 로고 → 교환·반품

**교차 패턴 (추정, 확신 상)**
- 특징 구간(S14~S21)은 '글 블록(약 650~700px) → 사진/GIF(약 860~1,100px)'가 8번 반복됨.
- 글 블록 하나는 번호 원, 제목 1줄, 본문 2~3줄로 이뤄짐.
- 다크 섹션(S10, S22, S24)이 대략 1/4, 3/4, 끝 근처에 한 번씩 들어가 단조로움을 끊음.

**같은 레이아웃 반복 (측정)**
- S16, S19, S20은 간격(237~244 / 61 / 74 / 19)과 글자 크기(58 / 31)가 픽셀 단위로 같음.
- 템플릿 하나를 복제해서 쓴 것으로 보임.

**강조 방식 (측정)**
- 크기(제목 58 vs 본문 31)와 굵기(본문 안 핵심어)만 씀. 색 강조는 안 씀.
- 예외: 배너 S03은 주황 숫자 강조를 씀(추정). 레시피 라벨은 노랑 스크립트.

**한 섹션당 메시지 수 (추정)**
- 특징 섹션: 1개(제목 1개 = 메시지 1개)
- 요약 섹션(S06, S12): 4~6개
- 후기(S11): 3개
- 사용법(S23): 5단계

**정보 반복 (추정, 확신 상):** 같은 장점(크기, 다양한 요리, 코팅, 쉬운 사용 등)이 S06(아이콘) → S12(카드) → S14~S22(상세)에서 **3번** 나옴.

### 규칙으로 뽑을 만한 것

형식: `[ID] 규칙(수치) — 이유 — 예외`

- **[TY-01]** 섹션 제목과 본문의 잉크 높이 비율을 **약 0.5**(860 폭 기준 제목 58px / 본문 31px, 폰트 크기 약 64~70 / 34~38px)로 고정한다.
  - 이유: 모든 특징 섹션에서 같은 위계가 유지되어 훑어보기 쉬움 (S16, S19, S20 측정).
  - 예외: 히어로 제품명(잉크 54px)과 스펙·정책 표(잉크 20~23px)는 별도 단계로 둔다.
- **[SP-01]** 특징 블록 간격은 **섹션 위 240 / 번호→제목 60 / 제목→본문 74 / 본문 줄 사이 19**(860 기준)로 쓴다. 그룹 안 간격과 그룹 사이 간격의 비율은 약 1:3 이상으로 둔다.
  - 이유: 같은 템플릿에서 3번 측정된 값이고, 그룹이 분명히 갈라짐.
  - 예외: 사진이 위아래로 이어지는 연출 섹션에는 단색 여백 대신 사진 자체를 여백으로 쓴다.
- **[CL-01]** 글자색은 **#323232 한 가지**(다크 배경에서는 #FFFFFF), 강조는 **굵기만** 쓴다. 본문 대비는 **10:1 이상**을 유지한다.
  - 이유: 측정한 9곳 중 8곳이 10:1을 넘고, 배경 색조가 바뀌어도 통일감이 유지됨.
  - 예외: 가격·이벤트처럼 숫자를 강조해야 하는 배너는 포인트색 1개를 허용한다.
- **[LY-01]** 본문 글 최대 폭은 860 폭의 **약 73%(625px 이하)**, 가운데 정렬, 한 블록 **2~3줄**로 쓴다.
  - 이유: 측정한 특징 본문이 모두 2~3줄, 최대 625px이었고, 한 번에 읽히는 분량임.
  - 예외: 사용법 단계·스펙 표·정책은 왼쪽 정렬로 쓴다 (S23, S27, S29).
- **[RH-01]** 글 블록(약 650~700px)과 사진/GIF(약 860~1,100px)를 번갈아 놓고, 페이지 1/4마다 다크 섹션을 하나 넣는다. 같은 장점은 **요약 1번 + 상세 1번까지만** 쓴다.
  - 이유: 교차 리듬은 효과가 있었지만 3번 반복이 길이를 늘림 (S06, S12, S14~S21).
  - 예외: 첫 화면 요약(S06 같은 아이콘 그리드)은 상세와 겹쳐도 1번 허용한다.
